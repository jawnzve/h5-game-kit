# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-27

### Added
- 初始版本，基于 ETH Zurich 论文 "Evaluating AGENTS.md" (Feb 2026)
- 极简主义原则：目标 30 行以内
- 工具为中心：提取具体命令而非概念解释
- 陷阱驱动：只写 Agent 无法发现的信息
- 标准模板：Tooling + Required Services + Non-Obvious Rules
- 反模式清单：明确禁止的内容
- 多平台支持：CLAUDE.md / AGENTS.md / .cursorrules

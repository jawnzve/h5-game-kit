# 论文核心发现

来源：ETH Zurich, "Evaluating AGENTS.md", Feb 2026
arXiv: 2602.11988

## 关键数据

| 上下文文件类型 | 对 Agent 性能影响 | 成本影响 |
|-------------|----------------|---------|
| LLM 生成（长） | -3% | +23% |
| LLM 生成（短） | +0.3% | +3% |
| 人工极简 | +4% | - |
| 无文档仓库 | +2.7% | - |

## 核心结论

1. **Concise is Key**: 30 行以内效果最好
2. **Tool mentions matter**: 提及工具使 Agent 使用率从 0.01 跳到 1.6x/任务
3. **Human > LLM**: 人工写的极简文件优于 LLM 生成的详细文件
4. **Discoverability**: Agent 能自己发现的信息不需要写

## 实践建议

- 文档完善的仓库：5-10 行足够
- 无文档的仓库：最多 40 行
- 重点：具体命令 + 非显而易见规则 + Agent 陷阱
